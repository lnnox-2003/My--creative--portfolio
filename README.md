# Innocent Zinhoro — Personal Portfolio

A responsive static portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Project structure

- `index.html` — page structure and content
- `styles.css` — responsive styling and three-colour design system
- `script.js` — mobile navigation, expanded project case studies, scroll reveals and active navigation
- `assets/` — supplied project cover images and CV PDF

## Run locally

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub and Vercel

1. Create a GitHub account (if you do not already have one).
2. Create a new repository, for example `innocent-zinhoro-portfolio`.
3. Upload the contents of this folder to the repository root. Make sure `index.html`, `styles.css`, `script.js` and `assets/` are at the top level.
4. Sign in to Vercel with GitHub at https://vercel.com/.
5. Choose **Add New → Project**, import your portfolio repository and keep the framework preset as **Other**.
6. Leave the build command and output directory empty; this is a static HTML website.
7. Select **Deploy**. Vercel will provide a public `*.vercel.app` URL.
8. Later, update files in GitHub and push/commit the changes. Vercel automatically redeploys the site.

## Project case studies

Each of the four supplied project covers opens an expanded case-study panel with the project focus, visible creative direction, relevant capabilities and a transparent scope note. The descriptions are intentionally limited to information visible in the supplied covers and the CV. The CV lists Canva, Photoshop, Figma, CapCut and InShot as tools, but does not assign individual tools or exact responsibilities to each project. No campaign metrics or business outcomes have been added.

The visual identity uses three primary brand colours: deep navy, electric violet and soft off-white. Supporting shades and transparency variations are used for readable text hierarchy and contrast.

## Before publishing

- The four Canva URLs are the links supplied with the project. Confirm their sharing permissions are set so intended visitors can view the presentations.
- The Figma URL could not be opened by the review environment, so the supplied reference screenshots informed the visual direction.
- The CV is included as a downloadable PDF. It contains your phone number and email address; keep it public only if you are comfortable sharing those details.
- The supplied CV lists certifications but does not include issuing organisations or dates, so the website does not add them.
- No employment role, employer, measured campaign result, social profile URL or achievement was invented. Add verified details when you provide them.
- Replace any project copy if the full Canva presentations contain more precise project objectives, your exact role, tools or outcomes.
